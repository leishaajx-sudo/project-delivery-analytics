# Project Delivery Analytics

An automated pipeline that pulls public issue and milestone data from the
Hack for LA website repository, models it in SQL, and forecasts milestone
completion dates in Power BI.

**Status:** Week 1 of 6, charter and setup.

## Planned stack
Python, PostgreSQL, SQL, Power BI (DAX), GitHub Actions

## Planned metrics
Velocity, cycle time, burndown, schedule variance (SPI), Monte Carlo forecast
